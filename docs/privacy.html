栖点隐私政策

适用版本：1.0.0　生效日期：2026年9月30日

栖点是一款替换 Microsoft Edge 新标签页的个人起始页扩展。扩展发布者以 Microsoft Edge 扩展商店页面显示的开发者为准。本政策说明扩展如何访问、保存和传输数据。

1. 本地保存的数据

网址标题与地址、分组、文件夹、卡片顺序与尺寸、搜索引擎设置、时钟与外观设置、笔记、待办、纪念日、工具输入、游戏进度与纪录、节假日文件，以及用户选择的壁纸和图标图片，保存在当前浏览器的本地存储或 IndexedDB 中。不会自动同步到账号或上传给发布者。网页图标和天气、热搜缓存也保存在本机。

扩展没有发布者自建的数据接收服务器，没有广告、遥测、使用统计或追踪脚本。首次使用说明的已读标记只保存在本机。

2. 访问浏览器信息

点击工具栏扩展按钮时，扩展读取当前活动网页的标题和地址，供你确认并保存网址。不会读取网页正文、密码、Cookie，也不会批量遍历浏览历史。网页图标通过 Edge 提供的 favicon 接口读取，不会向第三方图标代理提交网址。

只有你选择“导入 Edge 收藏夹”并授权后，扩展才读取收藏夹中的标题、地址和文件夹结构，将其复制为本地网址分组。扩展不会修改或删除原收藏夹。

3. 可选的联网功能

功能与触发条件发送的数据和接收方
天气：主动开启后刷新所选城市或确认过的经纬度发送至 api.open-meteo.com。服务还会收到网络请求的 IP 地址及常规请求信息。
当前位置：点击读取，再确认结果浏览器或系统返回一次设备位置。扩展立即将坐标取整到 0.1°；你再次确认前，不保存该坐标，也不发送给天气接口。确认后只保存和发送取整后的坐标，不持续定位。
微博、知乎、百度榜单：主动开启后刷新榜单标识（如 zhihu）发送至 newsnow.busiyi.world；不会附带你的网址库、笔记或搜索内容。服务会收到 IP 地址及常规请求信息。
游研社：主动开启后刷新向 www.yystv.cn 请求公开 RSS 文章列表，服务会收到 IP 地址及常规请求信息。
搜索与点击网址提交搜索时，在新标签页打开所选搜索引擎，将输入的查询词放入其搜索地址。选择本地网址搜索时，扩展只在本机匹配。点击网址或热搜条目会打开相应第三方网站。

联网数据使用 HTTPS 传输。天气和榜单接口请求不附带 Cookie，并采用不发送来源网址的策略。第三方服务的处理规则由其运营者负责，栖点无法控制第三方日志的保留。

Open-Meteo 的使用和隐私条款见 Open-Meteo Terms & Privacy。其他服务与搜索网站请查阅相应网站的隐私说明。系统定位本身也受 Microsoft Edge、操作系统和定位提供方的规则约束。

4. 备份与迁移

你主动导出的 .qidian.json 备份文件包含完整的界面设置、网址、笔记、组件数据、确认过的天气坐标、壁纸和自定义图标图片。文件是可读的 JSON，未经加密；扩展不会自动上传它。请由你选择保存、转移和分享位置。导入前会显示内容预览，确认恢复后才替换当前布局，并保留导入前的本机快照。

5. 保留、关闭与删除

工作区数据在本地保留，直到你修改、删除或卸载扩展。本机快照保留最近 20 份；它可能保留删除或修改前的内容。网页图标缓存最多使用 30 天，服务缓存超过 7 天不再读取；过期缓存不保证立即从磁盘清除。

在天气或热搜组件设置中关闭“启用”后，扩展停止之后的新请求；已有缓存可能继续保留。你可在 Edge 的扩展管理中撤销可选站点权限与收藏夹权限，或禁用扩展。已发出的请求不一定能撤回。卸载扩展会移除其浏览器本地数据，但不会删除你已导出的备份文件；可自行删除这些文件。卸载前请按需备份。

6. 数据用途与联系

扩展仅为你使用上述起始页功能处理数据，不出售用户数据，不进行广告画像，也不将数据用于与这些功能无关的目的。扩展无需注册账号，不主动索取身份、付款或健康信息。

有关隐私、数据处理或产品问题，请通过扩展商店页面公开的支持渠道联系发布者。

7. 政策更新

当功能或数据处理方式发生变化时，发布者将更新本政策和生效日期，并在新的商店版本中反映这些变化。浏览器中的扩展版本与公开政策版本应保持一致。
